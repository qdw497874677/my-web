# ADR 0002：将 AI 生图作为可选编辑部插件

## Status

Accepted

## Context

同一个生图模板应能使用不同供应商的模型。模板只描述任务和所需能力，不能依赖供应商的协议或参数。同时，生成会向第三方发送用户输入，可能产生费用，不应成为公开刊物的默认能力。

## Decision

- 在现有所有者认证范围内注册独立的 Fastify 插件，在编辑部提供独立页面。未配置时不调用供应商、不要求密钥。
- 模板声明成图比例和参考图张数；模型注册表声明支持的比例和最多参考图数量。服务端匹配并校验二者，前端只展示结果，不实现供应商判断。
- 协议适配器负责校验并映射供应商配置、构造请求和解析响应。内部模型返回单张内联栅格图，应用不跟随供应商返回的外部图片 URL。
- 首版同步处理，限制上传、响应大小、生成次数、并发和超时，不自动重试。生成结果仅预览、下载，不写入数据库或图片资产库。

## Consequences

新增模板或兼容模型不需要修改另一侧；新协议在后端插件内扩展。无需改变现有内容模型、存储或部署拓扑。插件不提供任务历史或跨进程配额；需要时应重新评估队列和持久化，而不是扩大现有同步请求的职责。
