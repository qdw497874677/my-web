# ADR 0003：在模块化单体中接入个人工作台工具

## Status

Accepted

## Context

公开刊物继续服务访客。个人工作台供唯一的刊物所有者使用。生图是第一个与刊物内容无关的工具，但此前进入生图也会加载公开和私有刊物列表；刊物请求与所有者会话、布局和工具入口耦合。

## Decision

- 保留现有公开页面、`/admin/...` 和 API URL。前端组合入口显式接入页面与导航，私有宿主管理会话和布局；刊物公开读区、刊物编辑区和生图工具分别加载自己的数据。生图工具与其导航共用一份目录状态，不依赖刊物列表。
- 后端工具仍显式注册在 Fastify 所有者鉴权范围内。菜单是否可见不参与授权。新增工具只注入该工具需要的依赖；确有替换或测试价值时再定义端口，生图的 `ImageModel` 是现成实例。
- 保留单进程、SQLite、集中迁移与刊物事务。栏目、文章、相册、收藏及资产不拆成可开关的插件。现有公开图片读取入口不能用作私有附件读取入口。

## Consequences

第一方工具随仓库构建发布，不是安全沙箱，也没有独立资源隔离。本轮不引入动态装载、插件 SDK、事件总线、任务队列或独立部署。等第二个实际工具出现，再从重复的接入代码提取公共契约；如需独立发布、故障隔离或运行第三方代码，另行决策。
